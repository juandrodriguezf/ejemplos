# Git Local 1 (Fundamentos SW)

Este es un repositorio local utilizado para sincronizar proyectos y tareas del séptimo semestre y realizar pruebas de temas variados.

## 🚀 Proyectos en este Repositorio:

1.  **`test.py`**: Programa básico de prueba en Python (v3.12).
2.  **`web_prueba/`**: Landing Page moderna con diseño Glassmorphism y Dark Mode.
3.  **`airline_web/`**: Buscador de vuelos para la aerolínea "SkyHigh Airlines".

## 🛠️ Herramientas y Configuración:
- **Servidor Local**: Python HTTP Server (Recomendado en puerto `8080`).
- **IDE**: Antigravity (Basado en VS Code).
- **Control de Versiones**: Git & GitHub (Rama `main`).
